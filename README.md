# cafeteria-clase-26-27
Ejercicio de clase para ver ramas, pull requests y conflictos

Equipo de cuatro. Repo compartido con main protegida si el plan del centro lo permite; si no, acuerdo de no empujar a main.
- Persona A: rama feat/estilos y cambia el CSS global.
- Persona B: rama feat/carta y añade sección en index.html.
- Persona C: rama feat/textos y modifica el mismo párrafo del header que B también toca.
- Persona D: rama/footer y añade sección en index.html y en el CSS global.

Cada cual abre un PR hacia main. El de C o el de B chocará. Puede que el D también. Se resuelve en local o en GitHub, se documenta y se mergea.
Al final: cuatro PR, al menos un conflicto resuelto, main coherente.
